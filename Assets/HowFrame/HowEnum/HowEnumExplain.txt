一、系统概述
--------------------------------------------------------------------------------
HowFrame Enum 系统是一个基于类型安全的枚举键值系统，用于替代传统的 C# enum。
该系统通过泛型 Tag 机制实现类型安全，避免不同枚举类型之间的混淆。

核心特点：
- 类型安全：通过泛型 Tag 区分不同的枚举类型
- 支持嵌套结构：可以创建分组的枚举项
- 可视化编辑：提供 Unity 编辑器工具进行可视化编辑
- 代码自动生成：从 JSON 配置自动生成 C# 代码
- 字符串转换：支持字符串与枚举键值之间的双向转换

二、核心组件
--------------------------------------------------------------------------------

2.1 EnumKey<TTag> - 核心类型
--------------------------------------------------------------------------------
位置：HowFrame/HowEnum/EnumKey.cs

EnumKey<TTag> 是系统的核心类型，使用泛型参数 TTag 来区分不同的枚举类型。
每个枚举类都有自己的 Tag 类型，确保类型安全。

结构：
```csharp
public record EnumKey<TTag> : EnumKeyBase
{
    public string name;  // 枚举项的名称（完整路径）
    internal EnumKey(string name);  // 带名称的构造函数
    internal EnumKey();              // 无参构造函数（自动生成名称）
}
```

特性：
- 使用 record 类型，支持值相等性比较
- name 字段存储枚举项的完整路径（如 "Body.Hight"）
- 构造函数为 internal，只能由生成的枚举类使用

2.2 生成的枚举类结构
--------------------------------------------------------------------------------
位置：HowFrame/HowEnum/Enums/*.cs

每个枚举类都是静态类，包含：
- Tag 嵌套类：用于类型区分
- 静态只读字段：每个枚举项都是 EnumKey<Tag> 类型
- 嵌套静态类：支持分组结构（可选）
- Convert 方法：字符串转枚举键值（可选）
- GetAll 方法：获取所有枚举项（可选）

示例结构：
```csharp
namespace HowEnum
{
    public static class PlayerEnum
    {
        public class Tag { }  // 类型标记
        
        // 顶层枚举项
        public static readonly EnumKey<Tag> HP = new("HP");
        public static readonly EnumKey<Tag> SP = new("SP");
        
        // 嵌套分组
        public static class Body
        {
            public static readonly EnumKey<Tag> Hight = new("Body.Hight");
            public static readonly EnumKey<Tag> Weight = new("Body.Weight");
        }
        
        // 可选：Convert 方法
        public static EnumKey<Tag> Convert(string value) { ... }
        
        // 可选：GetAll 方法
        public static List<EnumKey<Tag>> GetAll() { ... }
    }
}
```

三、编辑器工具（HowEditor/EnumCreator）
--------------------------------------------------------------------------------

3.1 EnumCreator - 可视化编辑器窗口
--------------------------------------------------------------------------------
位置：Editor/HowEditor/EnumCreator/EnumCreator.cs

功能：
- 提供 Unity 编辑器窗口用于创建和编辑枚举定义
- 支持可视化编辑枚举项和嵌套结构
- 自动保存/加载配置
- 一键导出 JSON 和 C# 代码

使用方法：
1. 在 Unity 编辑器中打开：Tools > Enum Creator
2. 输入枚举名称（会自动添加 "Enum" 后缀）
3. 配置输出参数：
   - 命名空间（默认：HowEnum）
   - JSON 输出路径（默认：Assets/Editor/HowEditorConfig/EnumConfig）
   - C# 输出路径（默认：Assets/HowFrame/HowEnum/Enums）
   - 是否启用 Convert 方法
   - 是否启用 GetAll 方法
4. 添加枚举项：
   - 取消勾选"子集合"：添加普通枚举项
   - 勾选"子集合"：创建嵌套分组
5. 点击"一键导出 JSON + C# 脚本"生成代码

3.2 EnumGenerater - 代码生成器
--------------------------------------------------------------------------------
位置：Editor/HowEditor/EnumCreator/EnumGenerater.cs

功能：
- 根据 EnumRoot 数据结构生成 C# 枚举类代码
- 支持嵌套类结构
- 可选生成 Convert 和 GetAll 方法

生成规则：
- 普通元素 → 静态只读字段
- 子集合 → 嵌套静态类
- 路径命名：嵌套项使用 "父类.子项" 格式

3.3 数据结构
--------------------------------------------------------------------------------

EnumRoot（Editor/HowEditor/EnumCreator/EnumRoot.cs）：
- collectionName: 枚举类名称
- elements: 枚举元素列表

EnumElement（Editor/HowEditor/EnumCreator/EnumElement.cs）：
- isList: 是否为子集合（嵌套类）
- value: 枚举项名称（普通元素）
- groupName: 分组名称（子集合）
- children: 子元素列表（子集合）

3.4 JSON 配置格式
--------------------------------------------------------------------------------
位置：Editor/HowEditorConfig/EnumConfig/*.json

JSON 格式示例：
```json
{
  "collectionName": "PlayerEnum",
  "elements": [
    "HP",
    "SP",
    "EXE",
    {
      "groupName": "Body",
      "children": ["Hight", "Weight", "YYP"]
    }
  ]
}
```

说明：
- 字符串元素：普通枚举项
- 对象元素：嵌套分组，包含 groupName 和 children

3.5 EnumHelper - JSON 序列化辅助
--------------------------------------------------------------------------------
位置：Editor/HowEditor/EnumCreator/EnumHelper.cs

功能：
- Serialize: 将 EnumRoot 序列化为 JSON
- Deserialize: 将 JSON 反序列化为 EnumRoot

四、运行时使用
--------------------------------------------------------------------------------

4.1 基本使用
--------------------------------------------------------------------------------

访问枚举项：
```csharp
using HowEnum;

// 直接访问
var hp = PlayerEnum.HP;
var height = PlayerEnum.Body.Hight;

// 获取名称
string name = hp.name;  // "HP"
string fullName = height.name;  // "Body.Hight"
```

4.2 类型安全
--------------------------------------------------------------------------------

不同枚举类型不能混用：
```csharp
// ✅ 正确：相同类型
PlayerEnum.HP == PlayerEnum.SP  // 可以比较

// ❌ 错误：不同类型（编译错误）
// PlayerEnum.HP == LangModuleEnum.UI  // 编译错误，类型不匹配
```

4.3 字符串转换（如果启用了 Convert 方法）
--------------------------------------------------------------------------------

字符串转枚举键值：
```csharp
// 从字符串创建枚举键值
var hp = PlayerEnum.Convert("HP");
var height = PlayerEnum.Convert("Body.Hight");

// 如果枚举类支持反向转换
string str = LangModuleEnum.Convert(LangModuleEnum.UI);  // "UI"
```

4.4 获取所有枚举项（如果启用了 GetAll 方法）
--------------------------------------------------------------------------------

```csharp
// 获取所有枚举项
var allItems = PlayerEnum.GetAll();
foreach (var item in allItems)
{
    Debug.Log(item.name);
}
```

4.5 实际应用示例
--------------------------------------------------------------------------------

在事件系统中使用：
```csharp
// 使用枚举键值作为事件标识
EventAssistant.Send(GlobalEventEnum.LanguageChange);

// 在语言系统中使用
LangManager.GetText(LangModuleEnum.UI, "ButtonOK");
```

六、工作流程
--------------------------------------------------------------------------------

1. 设计阶段
   - 确定枚举名称和结构
   - 规划是否需要嵌套分组

2. 编辑阶段
   - 打开 Tools > Enum Creator
   - 输入枚举名称
   - 添加枚举项（普通项或嵌套分组）
   - 配置输出参数

3. 生成阶段
   - 点击"一键导出 JSON + C# 脚本"
   - 系统自动生成：
     * JSON 配置文件（Editor/HowEditorConfig/EnumConfig/）
     * C# 枚举类（HowFrame/HowEnum/Enums/）

4. 使用阶段
   - 在代码中引用生成的枚举类
   - 使用枚举键值进行类型安全的操作

5. 维护阶段
   - 需要修改时，在 Enum Creator 中加载现有配置
   - 修改后重新导出
   - 注意：手动修改生成的 C# 代码会在下次导出时被覆盖

七、最佳实践
--------------------------------------------------------------------------------

1. 命名规范
   - 枚举类名以 "Enum" 结尾（如 PlayerEnum）
   - 枚举项使用 PascalCase（如 HP, Body）
   - 嵌套分组使用有意义的名称（如 Body, Config）

2. 结构设计
   - 相关枚举项使用嵌套分组组织
   - 避免过深的嵌套层级（建议不超过 2-3 层）
   - 保持枚举项的语义清晰

3. 方法选择
   - 需要字符串序列化/反序列化时启用 Convert 方法
   - 需要遍历所有枚举项时启用 GetAll 方法
   - 简单枚举可以只保留基本结构

4. 类型安全
   - 始终使用强类型的 EnumKey<Tag>，避免使用字符串
   - 利用编译时类型检查避免错误

5. 配置管理
   - JSON 配置文件应纳入版本控制
   - 生成的 C# 代码可以忽略（会自动重新生成）

八、技术细节
--------------------------------------------------------------------------------

8.1 类型安全机制
--------------------------------------------------------------------------------
通过泛型 Tag 实现类型安全：
- 每个枚举类定义自己的 Tag 嵌套类
- EnumKey<Tag> 中的 TTag 参数确保不同枚举类型不能混用
- 编译时检查，避免运行时错误

8.2 路径命名规则
--------------------------------------------------------------------------------
- 顶层枚举项：直接使用项名（如 "HP"）
- 嵌套枚举项：使用 "父类.子项" 格式（如 "Body.Hight"）
- 多级嵌套：使用点号分隔（如 "Config.UI.ButtonOK"）

8.3 代码生成策略
--------------------------------------------------------------------------------
- 使用 StringBuilder 构建代码字符串
- 递归处理嵌套结构
- 自动处理命名空间和缩进
- 可选生成辅助方法（Convert, GetAll）

8.4 序列化格式
--------------------------------------------------------------------------------
- JSON 格式：字符串表示普通项，对象表示嵌套分组
- 使用 LitJson 进行序列化/反序列化
- 配置文件存储在 Editor 目录下，避免打包

九、常见问题
--------------------------------------------------------------------------------

Q1: 为什么使用 EnumKey 而不是 C# enum？
A1: 
- 支持运行时动态创建和修改
- 更好的序列化支持（字符串）
- 支持嵌套分组结构
- 类型安全且易于扩展

Q2: 如何修改已生成的枚举？
A2:
- 在 Enum Creator 中加载对应的 JSON 配置
- 修改后重新导出
- 注意：手动修改的 C# 代码会被覆盖

Q3: 生成的代码在哪里？
A3:
- JSON 配置：Editor/HowEditorConfig/EnumConfig/
- C# 代码：HowFrame/HowEnum/Enums/

Q4: 如何在不同枚举类型之间转换？
A4:
- 不能直接转换，这是类型安全的特性
- 可以通过字符串作为中间格式进行转换
- 使用 Convert 方法进行字符串 ↔ 枚举键值转换

Q5: 枚举项的名称可以重复吗？
A5:
- 同一枚举类内的顶层项不能重复
- 不同嵌套分组内可以有相同名称的项（但路径不同）
- 建议保持全局唯一性以便于管理
